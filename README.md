 📊 Formação Intensiva: Python para Análise de Dados Júnior

Seja bem-vindo(a) ao repositório do meu curso focado em fundamentos e lógica de programação com Python aplicados à Análise de Dados. Este material foi totalmente desenvolvido por mim utilizando o Google Colab e estruturado de forma didática para guiar novos profissionais do absoluto zero ao nível intermediário.

---

## 🎯 Objetivo do Projeto
Demonstrar habilidades de **Design Instrucional**, **Arquitetura de Código Organizado** e **Documentação Técnica**, provando o domínio sólido sobre a base da linguagem Python através da habilidade de estruturar e ensinar lógica para terceiros.

---

## 🧠 Nota de Design Instrucional (Decisão de Engenharia)
> ⚠️ **Aviso Pedagógico:** Este repositório foi construído intencionalmente com foco 100% pedagógico para desenvolvedores iniciantes. As soluções de código foram desenhadas de forma linear, explícita e descritiva (utilizando cadeias de `if/elif` e loops visuais tradicionais) para facilitar a absorção dos conceitos básicos de controle de fluxo. Abstrações avançadas, refatorações complexas (Clean Code) e tratamento dinâmico de exceções serão o foco do **Volume 2 (Módulo Avançado)**.

---

## 🛠️ O que você vai encontrar neste Notebook:
*   **Fundamentos Sólidos:** Variáveis, operadores matemáticos e controle de decisão (`if/elif/else`).
*   **Estruturas de Repetição:** Comparativos visuais práticos entre loops `For` e `While`.
*   **Manipulação de Dados:** Trabalho prático com Listas, Tuplas e Dicionários para simular cenários reais de negócios (como cadastros de funcionários).
*   **Modularização:** Construção de funções dinâmicas com parâmetros e retornos bem definidos.
*   **Desafios Integradores:** Exercícios práticos e testes de revisão criados para fixação do conteúdo.
